## Running them
- Run them as one campaign with six ads: the platform shows each person the feature that suits them. After 3–4 days, keep
  the two or three with the lowest cost per install.
- Good pairs: AI Tutor + Mock for "serious" students; Game Zone + Leaderboards for younger audiences; Offline for
  areas with costly data; Live classes for paid-class promotions.
